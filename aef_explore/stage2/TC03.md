GAP as posed: every label-free accuracy predictor reads model OUTPUTS and needs a trained head plus target inference; none asks whether the geometry of a frozen unit-norm EO embedding forecasts cross-region probe loss before any probe exists. COMPETITOR DIFF: SHRUG-FM needs a task model + target inference and abstains per pixel, TC03 needs neither and predicts the region-pair drop magnitude. HONEST CAVEAT: regressing accuracy on a feature-space divergence is NOT new (2007.02915); the only new part was the vMF/directional form, and the pilot shows it is the worst variant.
SCOPE vs TE06: TE06 = MECHANISM (does static DEM/ERA5 input dependence CAUSE the loss; input ablation / TESSERA contrast). TC03 = PREDICTOR (can a label-free statistic forecast the loss), agnostic to cause. Independent claims, no merge — but see DONATE below.
