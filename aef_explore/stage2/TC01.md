# TC01 (seed S4) — Static/climate-input dependence as the mechanism of AEF cross-region transfer loss

## 1. Literature (전부 in-session 검증 [V])
- Rahman 2026, arXiv:2602.10354 [V]: AEF 64 dim이 elevation/temperature 등 물리량으로 R2~0.97 수준 decodable (CONUS). dimension-level decodability의 원전.
- Benavides-Martinez et al. 2026, arXiv:2603.16911 [V] "What on Earth is AlphaEarth?": 64 dim 중 2-12개만으로 land-cover ~98% 재현 → 정보가 소수 dim에 집중.
- Lehmann et al. 2026, arXiv:2608.16614 [V] "Beyond Accuracy": GFM(AEF 포함) calibration과 distribution shift 민감도. **최강 경쟁자.**
- 2602.17250 [V] (height decodability), 2601.16900 [V] (Senegal crop type, region-specific probe) — decodability/전이 주변 근거.
- Gap: decodability는 확립됐지만 (i) 그 subspace가 cross-region transfer 손실을 실제로 유발하는지, (ii) 제거/residualise가 in-domain 대가 없이 transfer를 회복시키는지 아무도 측정하지 않았다. 2608.16614는 shift 하에서 *성능·calibration 저하*를 보고할 뿐 **어느 dim이 원인인지**를 귀속(attribution)하지 않는다 — TC01은 dim-level 인과 귀속 + 완화 레시피라는 점에서 다르다.

## 3. Smoke test (T3 Transfer + T4 Decodability)
n=1800/region, class balance 600/600/600 (stratified), metric = 3-class balanced accuracy (chance 0.333), 5-fold GroupKFold on 0.1°(~11 km) blocks, transfer = BR fold-train 모델 → CG 전체.
| feature set | in-domain(sd) | BR→CG transfer(sd) | drop |
|---|---|---|---|
| AEF 64 | 0.940 (0.016) | 0.555 (0.049) | +0.384 |
| **S2 annual median 8band (mandatory baseline)** | 0.907 (0.018) | **0.705 (0.023)** | +0.202 |
| statics only (elev/slope/tmean/prec) | 0.654 (0.020) | 0.376 (0.012) | +0.277 |
| AEF drop top-16 (pooled static-R2) | 0.942 (0.013) | 0.638 (0.008) | +0.304 |
| AEF drop top-16 (cross-region mean-shift) | 0.939 (0.016) | 0.630 (0.016) | +0.309 |
| AEF only top-16 static-decodable | 0.930 (0.012) | 0.629 (0.007) | +0.301 |
| AEF 64 residualised on statics (BR-fit) | 0.861 (0.015) | 0.538 (0.054) | +0.324 |
| AEF 64, per-region z-score | 0.940 (0.016) | 0.680 (0.012) | +0.260 |
Decodability: within-ROI ridge R2는 max 0.47 (>0.5 없음) — CONUS 광역 R2 0.97과 달리 100 km 내 static 변동이 작아 낮음. 두 ROI pooled 시 A34 0.72/A10 0.71/A18 0.71. **핵심: pooled static-R2 top-16과 cross-region mean-shift top-16이 14/16 일치** → 지역 식별 subspace ≈ terrain/climate decodable subspace. 그 16 dim 제거 시 in-domain 무손실(0.940→0.942, fold sd 내), transfer +0.083 회복(AEF-S2 격차 0.150의 약 55%). 단 residualise(BR-fit)는 양쪽 다 악화. AEF는 모든 변형에서 S2보다 transfer가 나쁘다.

## 4. Scoring / decision
N 3 | R 2 | F 3 | A 3 | V 3 | J 3 = **17/18** → **PASS**. 근거: 기존 문헌이 미측정한 인과 귀속을 pilot이 이미 재현했고(효과 크기 0.08-0.15, fold sd 0.01-0.05 대비 충분), GEE만으로 3개월 내 다지역 확장 가능, 결과가 실무 레시피(전이 시 static-decodable dim 제거)로 직결.
Top-3 risks: (1) 대륙별로 다른 label-product noise(Congo shrub/grass 혼동 vs BR pasture)가 transfer drop을 위조할 위험 → MapBiomas·LandCoverNet·DW 교차검증 + 다중 region pair. (2) static-decodable subspace와 일반 covariate-shift subspace가 14/16 중복 → "static input이 원인"과 "단순 domain shift"의 분리가 어렵고 TESSERA matched control이 GEE에 없음. (3) 단일 region pair·3 class·0.1° block → class-prior shift와 spatial autocorrelation 잔존, 일반화 미검증.
Reviewer 2: "top-k dim 제거 효과를 **임의 k-dim 제거**와 비교하지 않았고, per-region z-score(0.680)가 ablation(0.638)보다 더 좋으니 이건 static-input 의존이 아니라 평범한 covariate shift다." 선제 대응: (a) 동일 k의 random-dim ablation을 수백 회 뽑아 null 분포를 만들고 static-R2 ranking ablation의 위치를 검정, (b) pooled static-R2 ranking과 shift ranking의 14/16 중복에 permutation null 부여, (c) 동일 label·동일 shift를 겪는 S2 baseline의 drop(0.202)이 AEF(0.384)보다 작다는 대조로 "AEF 고유 성분"을 분리, (d) z-score(moment 정합)와 dim 제거를 조합/분해해 shift의 어느 성분이 static-decodable인지 명시.
